# T04 Mini Challenge

Create and open:

```text
learning-project/
├── README.md
├── docs/
│   └── goals.md
├── data/
│   └── sample.txt
└── src/
    └── hello.txt
```

Requirements:

1. Create at least one file from Explorer.
2. Create at least one from the integrated terminal.
3. Rename one file in Explorer.
4. Use Quick Open.
5. Use the Command Palette to open Settings.
6. Verify the workspace in the terminal.
7. Close VS Code.
8. Navigate to the folder in a terminal.
9. Run `code .`.
10. Explain what `.` means.

Then answer:

If the same project came from an unknown website and VS Code asked whether you trust the authors, what should you consider before granting trust?

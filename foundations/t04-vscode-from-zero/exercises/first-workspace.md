# T04 Exercise — Build Your First Workspace

Create:

```text
t04-first-workspace/
├── README.md
├── notes.txt
├── data/
├── docs/
└── src/
```

Open the folder in VS Code.

Add to `README.md`:

```markdown
# My First VS Code Workspace

I am learning how to work with folders and files in VS Code.
```

Add to `notes.txt`:

```text
VS Code is my learning workspace.
```

Then:

1. Create `docs/learning-notes.md`.
2. Rename it to `docs/vscode-notes.md`.
3. Create `data/sample.txt`.
4. Use Quick Open to open `README.md`.
5. Open multiple files in tabs.
6. Notice the language mode.

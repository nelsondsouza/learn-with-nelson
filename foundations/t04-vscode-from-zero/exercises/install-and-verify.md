# T04 Exercise — Install and Verify VS Code

Use only:

https://code.visualstudio.com/

Record:

```text
Operating system:
VS Code installed:
Install method:
```

Then test:

```text
code --version
```

If the command works, the VS Code CLI is available.

On macOS, if needed, use the Command Palette command:

```text
Shell Command: Install 'code' command in PATH
```

Then restart the terminal.

Explain in your own words what it means for `code` to be available from the terminal.

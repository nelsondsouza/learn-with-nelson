# T04 — Integrated Terminal Example

If the workspace folder is open in VS Code, the integrated terminal often starts with useful workspace context.

Verify instead of assuming.

PowerShell:

```powershell
Get-Location
Get-ChildItem
```

Bash/Zsh:

```bash
pwd
ls
```

The key idea:

> Explorer and the integrated terminal are two interfaces to the same file system and workspace.

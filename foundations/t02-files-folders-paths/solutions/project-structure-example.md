# T02 — Project Structure Example

```text
beginner-data-project/
├── README.md
├── data/
│   └── raw/
│       ├── sales.csv
│       └── customers.csv
├── docs/
│   ├── notes.md
│   └── screenshots/
├── src/
│   └── analysis.py
└── output/
    └── final-report.pdf
```

This separates source data, documentation, code, and generated output while keeping the README easy to discover. It is an example, not a universal standard.

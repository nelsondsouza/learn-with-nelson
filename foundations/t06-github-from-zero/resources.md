# T06 — Additional Resources

Use official GitHub documentation because authentication and UI flows evolve.

- About repositories: https://docs.github.com/en/repositories/creating-and-managing-repositories/about-repositories
- Create a repository: https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-new-repository
- Remote repositories: https://docs.github.com/en/get-started/git-basics/about-remote-repositories
- Manage remotes: https://docs.github.com/en/get-started/git-basics/managing-remote-repositories
- Authentication: https://docs.github.com/en/authentication
- Credential caching: https://docs.github.com/en/get-started/git-basics/caching-your-github-credentials-in-git
- Personal access tokens: https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens
- GitHub CLI: https://docs.github.com/en/github-cli/github-cli/quickstart
- Repository visibility: https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/managing-repository-settings/setting-repository-visibility
- Sensitive data: https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository

Do not rely on old tutorials that tell you to use your GitHub account password for Git-over-HTTPS operations.

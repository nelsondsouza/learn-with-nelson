# T06 Mini Challenge — Local to GitHub and Back

Create:

```text
remote-learning-project/
├── README.md
├── notes/
│   └── progress.md
└── .gitignore
```

Requirements:
1. initialize local Git on `main`;
2. create at least two commits;
3. create an empty GitHub repository;
4. add it as `origin`;
5. verify with `git remote -v`;
6. push with `git push -u origin main`;
7. verify on GitHub;
8. make another local commit and `git push`;
9. make a small README edit on GitHub;
10. locally run `git status` then `git pull`;
11. inspect `git log --oneline`;
12. clone into another safe directory;
13. inspect the clone's `origin`.

Explain local repository, remote repository, origin, push, pull, clone, upstream, `main`, and `origin/main`.

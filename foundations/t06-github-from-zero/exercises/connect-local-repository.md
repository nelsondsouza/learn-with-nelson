# T06 Exercise — Connect a Local Repository

Create locally:

```text
github-learning-project/
└── README.md
```

Initialize on `main`, create one commit, then add the GitHub repository HTTPS URL:

```text
git remote add origin YOUR-REPOSITORY-URL
git remote -v
```

Explain:
- what `origin` is
- what URL it points to
- whether anything has been uploaded yet

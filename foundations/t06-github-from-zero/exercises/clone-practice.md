# T06 Exercise — Clone Practice

From a safe parent directory:

```text
git clone REPOSITORY-URL
```

Enter the cloned directory and inspect:

```text
git status
git remote -v
git log --oneline
```

Explain:
1. Why `git init` is unnecessary after clone.
2. What remote exists.
3. What history is available.
4. How cloning differs from downloading a ZIP.

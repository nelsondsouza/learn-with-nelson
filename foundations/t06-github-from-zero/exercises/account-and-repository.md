# T06 Exercise — GitHub Account and Repository

Use https://github.com/.

Record only non-secret information:

```text
GitHub username:
2FA enabled or planned:
```

Create an empty repository named `github-learning-project`.

Choose public or private deliberately. Do not initialize it with README, `.gitignore`, or license for this exercise.

Answer:
1. Why did you choose public or private?
2. What would you inspect before making it public?
3. What is the repository URL?
4. Does creating it on GitHub automatically create a local folder?

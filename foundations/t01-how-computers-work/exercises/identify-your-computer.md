# T01 Exercise — Identify Your Computer

Connect T01 concepts to the computer you actually use. Do not install diagnostic software.

## Record your system

```text

GPU:

```

If you cannot find something, write `Not found yet`.

## Windows

Open **Settings → System → About** for processor, RAM, system type, and Windows information.

Open **Task Manager → Performance** and explore CPU, Memory, Disk, and GPU.

## macOS

Open **Apple menu → About This Mac**. Use **System Settings → General → About** and **System Information** for more detail.

## Linux

Desktop tools vary. If you already know the terminal, commands such as `lscpu`, `free -h`, and `lsblk` can help. Command-line work is formally introduced in T03, so using them is optional.

## Observe memory

Open several applications, inspect memory use, close one large application, and inspect again.

Explain why closing an application can free RAM without deleting its files from storage.

# T01 Exercise — Computer Components

## Match the component

Choose: CPU, RAM, SSD/HDD, GPU, motherboard, operating system.

A. Temporary working memory for running programs.  
B. Executes general-purpose instructions.  
C. Keeps files after power is removed.  
D. Connects major hardware components.  
E. Especially useful for suitable highly parallel workloads.  
F. Manages processes, memory, files, devices, and other resources.

## RAM or storage?

1. Holds saved photos long-term.
2. Provides working space to running applications.
3. Normally loses contents when power is removed.
4. Holds installed applications.
5. Opening many applications can increase use of this resource.

## Program or process?

1. An application installed on disk.
2. A currently running instance.
3. Something the operating system schedules for CPU time.
4. Software stored before launch.

## Put these in simplified order

- CPU executes instructions.
- You launch the application.
- The operating system locates the program.
- Required instructions/data are loaded into RAM.
- The application becomes usable.

## Application launch

1. You launch the application.
2. The operating system locates the program.
3. Required instructions/data are loaded into RAM.
4. CPU executes instructions.
5. The application becomes usable.

Real startup is more complex and operations may overlap.

## Mini challenge example

I would investigate Computer B first, but would not buy it from these specifications alone.

Its 16 GB RAM offers more working memory, and an SSD generally provides much faster storage access. The 512 GB capacity is smaller, so I would check whether it is sufficient. The CPU descriptions are inadequate because advertised clock speed alone is not a reliable processor comparison.

The lesson is to evaluate the whole system and the actual workload.

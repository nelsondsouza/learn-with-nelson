# T07 Exercise — Git and GitHub Workflow

Inside your Python learning project:

```text
git status
```

Review files, stage the working Python files, inspect:

```text
git diff --staged
```

Commit with a meaningful message such as:

```text
Add first Python programs
```

Then push to your GitHub learning repository.

Questions:

1. Does Git care that the files contain Python?
2. Does GitHub run Python automatically just because you pushed?
3. Why inspect the staged diff before publishing code?

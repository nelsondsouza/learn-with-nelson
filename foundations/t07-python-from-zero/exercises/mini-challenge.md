# T07 Mini Challenge — Personal Introduction Program

Create `src/introduction.py`.

Ask for:

- name
- age
- city
- technology the user wants to learn

Calculate age next year and print a short summary.

Requirements:

1. at least four variables
2. `input()`
3. integer conversion
4. one arithmetic operation
5. at least three `print()` calls
6. one useful comment
7. run successfully
8. intentionally create one safe error and repair it
9. commit with Git
10. push to GitHub

Do not use `if`, loops, lists, or functions yet.

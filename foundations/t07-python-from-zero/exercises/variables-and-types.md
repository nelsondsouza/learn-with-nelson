# T07 Exercise — Variables and Types

Create `src/variables.py`:

```python
name = "Alex"
age = 30
height = 1.75
is_learning = True

print(name)
print(age)
print(height)
print(is_learning)

print(type(name))
print(type(age))
print(type(height))
print(type(is_learning))
```

Add arithmetic and comparisons:

```python
a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)

print(a > b)
print(a < b)
print(a == b)
print(a != b)
```

Explain string, integer, float, boolean, `=`, and `==`.

# T07 Exercise — Install and Verify Python

Use official Python installation guidance.

Record:

```text
Operating system:
Python version:
Command used:
```

Try:

```text
python --version
```

or:

```text
python3 --version
```

On some Windows systems:

```text
py --version
```

Install the official Microsoft Python extension in VS Code.

Questions:

1. What is the Python interpreter?
2. What command runs Python on your system?
3. Why is the VS Code Python extension not the same as Python itself?

# T03 Exercise — Navigation Practice

Work only in a safe folder you control.

## Step 1

Move to your home directory.

PowerShell / Bash / Zsh:

```text
cd ~
```

Confirm your location.

## Step 2

Create:

```text
t03-practice
```

Then enter it.

## Step 3

Create:

```text
docs
data
src
```

Your tree should be:

```text
t03-practice/
├── data/
├── docs/
└── src/
```

## Step 4

Move into `docs`.

Confirm your current location.

## Step 5

Move back to the parent using:

```text
cd ..
```

## Step 6

Move to `src`.

Then navigate from `src` to `data` using a relative path.

Do not jump back to home first.

## Questions

1. What was the relative path from `src` to `data`?
2. What does `..` represent?
3. What command showed your current directory?
4. What command listed the directory contents?

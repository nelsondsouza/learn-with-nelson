# T03 Mini Challenge — Build a Project Tree from the Command Line

Work inside a safe practice location.

Without using the graphical file manager after you begin, create:

```text
command-line-project/
├── README.txt
├── data/
│   ├── raw/
│   └── processed/
├── docs/
└── src/
```

Put this text into `README.txt`:

```text
My first command-line project.
```

Then:

1. confirm your current directory
2. list the project contents
3. navigate into `data/raw`
4. navigate from `data/raw` to `src` using a relative path
5. return to the project root
6. display the contents of `README.txt`

Do not use recursive delete commands.

When complete, explain which commands you used and what each one did.

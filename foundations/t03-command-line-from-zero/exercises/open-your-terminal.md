# T03 Exercise — Open Your Terminal

## Windows

Open **Windows Terminal** if available.

You may also encounter:

- PowerShell
- Command Prompt

Record:

```text
Terminal application:
Shell:
Prompt shown:
```

Run:

```powershell
Get-Location
```

If you are in PowerShell, also try:

```powershell
pwd
```

Then:

```powershell
Get-ChildItem
```

## macOS

Open **Terminal**.

Record the prompt.

Run:

```bash
pwd
```

Then:

```bash
ls
```

## Linux

Open your desktop environment's terminal application.

Run:

```bash
pwd
```

then:

```bash
ls
```

## Reflection

Explain:

1. What is your terminal application?
2. What shell are you using?
3. What does your prompt appear to tell you?
4. What directory were you in when the terminal opened?

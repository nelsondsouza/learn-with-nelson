# T08 Exercise — Install and Verify SQLite

Use official SQLite sources:

https://sqlite.org/download.html

Verify:

```text
sqlite3 --version
```

Create/open a temporary practice database:

```text
sqlite3 practice.db
```

Inside the SQLite shell:

```sql
SELECT 1 + 1;
```

Exit using:

```text
.quit
```

Questions:

1. What is SQLite?
2. What is `sqlite3`?
3. Is `.quit` SQL?
4. What happened when you opened `practice.db`?

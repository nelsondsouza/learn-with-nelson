# T08 Exercise — Read the SQL Error

Run each broken query separately.

A:

```sql
SELECT student_name
FROM students;
```

B:

```sql
SELECT name city
FROM students;
```

C:

```sql
SELECT *
FROM student;
```

D:

```sql
SELECT *
FROM students
WHERE city = 'Dubai;
```

E:

```sql
SELECT *
FROM students
WHERE email = NULL;
```

For each:

1. read the error or unexpected result
2. identify whether it is syntax, naming, or logic
3. explain the problem
4. make one change
5. run again

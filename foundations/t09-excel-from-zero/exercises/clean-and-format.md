# T09 Exercise — Basic Cleaning and Formatting

Create a copy of a small dataset containing:

- inconsistent capitalization
- one blank cell
- an extra space in one text value
- inconsistent currency display
- inconsistent date display

Clean it manually.

Then apply:

- readable headers
- appropriate number formats
- sensible column widths
- no unnecessary merged cells inside the data table

Explain the difference between changing a value and changing only its display format.

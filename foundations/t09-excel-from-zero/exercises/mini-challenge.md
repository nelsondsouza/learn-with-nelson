# T09 Mini Challenge — Sales Analysis Workbook

Create a workbook from the supplied CSV.

Requirements:

1. import/open the sales data
2. add Total = Quantity × Unit Price
3. turn the dataset into an Excel Table
4. format currency columns
5. calculate total, average, minimum, maximum, and count
6. create a Tax Rate input cell
7. calculate after-tax totals using an absolute reference to the Tax Rate
8. sort largest Total first
9. filter one Region
10. create one column chart
11. save as `.xlsx`
12. explain three insights from the data

Do not use PivotTables or Power Query yet.

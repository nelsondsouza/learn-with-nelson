# T09 — Excel from Zero

T09 introduces spreadsheet thinking from the beginning.

The goal is not to teach every Excel feature. It is to help a complete beginner understand the workbook/worksheet/cell model, enter clean data, write basic formulas, understand cell references, use core functions, turn data into a Table, sort and filter, perform simple cleaning, and create one useful chart.

## Prerequisites

Complete T00–T08 first.

## Learning goals

You will learn:

- workbook vs worksheet
- rows, columns, cells, ranges
- cell addresses
- text, numbers, dates
- formulas and functions
- relative references
- absolute references
- mixed references at recognition level
- fill/copy formulas
- `SUM`, `AVERAGE`, `MIN`, `MAX`, `COUNT`, `COUNTA`
- basic arithmetic formulas
- percentage formulas
- Excel Tables
- sort and filter
- basic formatting
- simple data cleaning
- CSV vs XLSX
- one basic chart
- common Excel errors
- saving/versioning spreadsheet projects
- safe AI/Copilot assistance

## Deliberately not covered yet

T09 does not yet cover PivotTables, Power Query, XLOOKUP/VLOOKUP, IF/IFS, SUMIFS/COUNTIFS, dynamic arrays, dashboards, macros/VBA, Power Pivot, or advanced charts.

## Core mental model

```text
Workbook
  ↓
Worksheet
  ↓
Cells + Ranges
  ↓
Data + Formulas
  ↓
Table
  ↓
Analysis
  ↓
Chart / Insight
```

# T05 — Additional Resources

Use official Git documentation.

- Downloads: https://git-scm.com/downloads
- Reference: https://git-scm.com/docs
- Pro Git: https://git-scm.com/book/en/v2
- Getting a repository: https://git-scm.com/book/en/v2/Git-Basics-Getting-a-Git-Repository
- Recording changes: https://git-scm.com/book/en/v2/Git-Basics-Recording-Changes-to-the-Repository
- Viewing history: https://git-scm.com/book/en/v2/Git-Basics-Viewing-the-Commit-History
- `git status`: https://git-scm.com/docs/git-status
- `git commit`: https://git-scm.com/docs/git-commit
- `git restore`: https://git-scm.com/docs/git-restore

T05 deliberately avoids advanced/destructive workflows. Before running an unfamiliar Git command, understand its effect on the working tree, staging area, and commit history.

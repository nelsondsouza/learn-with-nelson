# T05 Exercise — Install and Configure Git

Use https://git-scm.com/downloads.

Run:

```text
git --version
```

Record your Git version, operating system, and shell.

Configure your own identity:

```text
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

Verify both values.

Explain why Git needs identity metadata, what `--global` means, and why configuring Git does not create a GitHub account.

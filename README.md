# Learn with Nelson

> Learn technology from zero — understand it, practice it, build with it.

Welcome to **Learn with Nelson**, a beginner-first learning library for people who want to build practical technology skills and careers.

You do not need a computer science degree.

You do not need programming experience.

You do not need to understand all the technical words you see online.

You just need somewhere sensible to start.

## 🚀 Start Here

If you are completely new to technology, begin with:

### [T00 — How to Start Learning Tech: A Complete Beginner's Guide](start-here/t00-how-to-start-learning-tech/)

You'll learn what computers, operating systems, files, terminals, programming languages, code editors, Git, GitHub, databases, APIs, cloud computing, and AI tools actually are — and how they fit together.

## 🧭 Choose Your Goal

The first career paths in this learning library are:

## 🧠 How We Learn

The goal is not to memorize everything.

You will:

**Understand → Follow Along → Practice → Make Mistakes → Build → Repeat**

AI tools can help you learn, but they should not replace understanding.

Throughout the tutorials, you'll learn how to use AI as a:
- teacher
- explainer
- debugging assistant
- brainstorming partner
- practice generator
- reviewer

You remain responsible for understanding and verifying the result.

---

## 🛠️ Projects

Learning becomes useful when you build something.

## 🤖 AI at Work

AI isn't treated as a separate world.

You'll learn how modern professionals use AI throughout their work while also understanding its limitations, risks, and the importance of verification.

Dedicated **AI at Work** paths will cover professions including developers, data analysts, ML engineers, project managers, architects, engineers, designers, and others.

## 📚 Tutorial Philosophy

Every full tutorial follows the same learning system:

1. What you'll learn
2. Before you start
3. Understand it
4. Follow along
5. Try it yourself
6. Common mistakes
7. Use AI 🤖
8. Mini challenge
9. Cheat sheet
10. What you now know
11. Next tutorial

No unexplained jumps. No assumption that you already know the basics.

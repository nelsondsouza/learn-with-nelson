# T00 — How to Start Learning Tech

## A Complete Beginner's Guide

Welcome.

If words such as **terminal, Git, API, database, cloud, IDE, repository, framework, or machine learning** sound confusing, you are in the right place.

This tutorial gives you a map of the technology world before we start exploring individual topics.

You are **not expected to master these concepts yet**.

Your goal is simply to understand:

> What are these things, why do people use them, and how do they fit together?

## About This Tutorial

By the end of T00, you should be able to explain in simple terms:

- what hardware and software are
- what an operating system does
- what files and folders are
- what a browser does
- what the internet and web are
- what programming means
- what source code is
- what a programming language is
- what a code editor or IDE is
- what a terminal is
- what Git does
- what GitHub does
- what a database is
- what an API is
- what cloud computing means
- where AI assistants fit
- how different technology careers relate to these concepts

You do not need previous programming experience.

For T00 you need:

- internet access

## Essential Vocabulary

### Hardware
The physical parts of a computer.

Examples: CPU, memory (RAM), storage, keyboard, mouse, monitor.

### Software
Instructions that tell hardware what to do.

Examples: Windows, macOS, Linux, Chrome, Excel, Visual Studio Code, Python programs.

### Operating System
The operating system manages the computer and provides a platform for applications.

Common examples: Windows, macOS, Linux, Android, iOS.

### File
A named piece of information stored on a computer.

Examples: `report.docx`, `photo.jpg`, `sales.xlsx`, `program.py`.

### Folder
A container used to organize files and other folders.

You may also hear the word **directory**. For now, folder and directory usually refer to the same basic concept.

### Browser
An application used to access websites and web applications.

Examples include Chrome, Edge, Firefox, and Safari.

### Internet
A global network connecting computers and networks.

### World Wide Web
A system of websites and web resources accessed over the internet.

The internet and web are related, but they are not the same thing.

### Programming
Writing instructions that a computer can execute.

### Source Code
Human-readable instructions written using a programming language.

Example:

```python
print("Hello, world!")
```

You do not need to understand this code yet. It simply asks Python to display `Hello, world!`.

### Programming Language
A language used to express instructions for computers.

Examples: Python, JavaScript, Java, C#, C++, Go.

### Code Editor
Software designed for writing and editing source code.

We will initially use **Visual Studio Code (VS Code)**.

### IDE
IDE means **Integrated Development Environment**.

An IDE combines several development tools into one application. Do not worry about the distinction between editors and IDEs yet.

### Terminal
A text-based interface for interacting with your computer.

Instead of clicking buttons, you type commands.

Example:

```text
cd projects
```

We will learn this safely from zero in T03.

### Git
Git tracks changes to files.

It allows developers to record changes, compare versions, return to earlier versions, create branches, and collaborate safely.

Git runs on your computer.

### GitHub
GitHub is an online platform that hosts Git repositories and provides collaboration features.

A useful beginner distinction is:

> Git is not GitHub.

You'll learn both separately.

### Database
A system for storing and retrieving organized data.

Examples: PostgreSQL, MySQL, SQLite, SQL Server, MongoDB.

### SQL
SQL is a language commonly used to work with relational databases.

Example:

```sql
SELECT name
FROM customers;
```

We will learn SQL from zero later.

### API
API means **Application Programming Interface**.

An API provides a defined way for software systems to communicate with each other.

For example, a weather application may request weather information from a weather service through an API.

### Cloud Computing
Cloud computing provides computing resources over networks instead of requiring everything to run on your own computer.

Examples of major cloud platforms include Amazon Web Services (AWS), Microsoft Azure, and Google Cloud.

### Artificial Intelligence
AI systems can perform tasks involving language, images, predictions, patterns, generation, and other capabilities.

Modern AI assistants can help you understand concepts, generate examples, brainstorm, debug, practice, and review work.

But AI can also produce incorrect information.

Throughout this learning program, you will learn to:

> **Ask → Understand → Verify → Apply**

rather than blindly copy AI output.

## Three Starting Career Paths

### 💻 Developer
Developers build software.

You may work with HTML, CSS, JavaScript, Python, APIs, databases, Git, and cloud platforms.

See [`diagrams/developer-path.mmd`](diagrams/developer-path.mmd).

### 📊 Data Analyst
Data analysts turn data into useful information.

You may work with Excel, SQL, Power BI, Python, statistics, visualization, and business metrics.

See [`diagrams/data-analyst-path.mmd`](diagrams/data-analyst-path.mmd).

### 🤖 ML Engineer
Machine Learning Engineers build and operationalize machine-learning systems.

You may work with Python, mathematics, statistics, NumPy, Pandas, machine learning, deep learning, MLOps, and cloud platforms.

See [`diagrams/ml-engineer-path.mmd`](diagrams/ml-engineer-path.mmd).

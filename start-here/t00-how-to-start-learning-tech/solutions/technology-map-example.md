# T00 — Technology Map Example

## Part 1 — Example Explanations

**Hardware:** The physical parts that make up a computer.

**Software:** Instructions and programs that run on computer hardware.

**Operating system:** Software that manages the computer and lets applications use its hardware.

**File:** A named collection of information stored on a device.

**Folder:** A way to organize files and other folders.

**Browser:** An application used to access websites and web applications.

**Internet:** The global network connecting computers and networks.

**Web:** Websites and web resources accessed using the internet.

**Programming:** Creating instructions for computers.

**Source code:** Human-readable instructions written in a programming language.

**Programming language:** A language used to express instructions that computers can ultimately execute.

**Code editor:** An application designed to write and edit source code.

**Terminal:** A text-based way to interact with a computer using commands.

**Git:** A version-control system used to track changes.

**GitHub:** An online platform for hosting Git repositories and collaborating on software.

**Database:** A system for storing and retrieving organized data.

**SQL:** A language commonly used to work with relational databases.

**API:** A defined interface through which software systems can communicate.

**Cloud computing:** Computing resources provided over networks when needed.

**Artificial intelligence:** Technology that enables systems to perform tasks involving capabilities such as language, pattern recognition, prediction, and generation.

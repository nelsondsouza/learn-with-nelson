# Contributing

Thank you for your interest in **Learn with Nelson**.

This repository is designed as a beginner-first learning library. Contributions should preserve that philosophy.

## Principles

Please keep contributions:

- beginner-friendly
- technically accurate
- practical
- concise where possible
- explicit about prerequisites
- free from unexplained jargon
- reproducible
- safe to follow

## Tutorial Structure

The full learning article for every tutorial follows this standard sequence:

1. What you'll learn
2. Before you start
3. Understand it
4. Follow along
5. Try it yourself
6. Common mistakes
7. Use AI 🤖
8. Mini challenge
9. Cheat sheet
10. What you now know
11. Next tutorial

GitHub companions do not need to duplicate the full article. They should focus on setup, code, exercises, solutions, datasets, diagrams, and reproducible learning material.

## Diagrams

Prefer diagram-as-code where practical:

- Mermaid for flows, sequences, states, timelines, and simple architecture
- DBML/dbdiagram for database schemas and ERDs
- PlantUML for richer UML
- Graphviz/DOT for graphs and dependency structures
- text-based wireframing tools when useful for UI concepts

## Pull Requests

Before submitting a pull request:

1. Verify instructions from a clean setup where practical.
2. Test code examples.
3. Check internal links.
4. Keep file and folder names lowercase with hyphens.
5. Avoid committing secrets, credentials, or private data.

Thank you for helping make technical learning easier to enter.
